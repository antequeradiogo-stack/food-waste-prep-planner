# Food Waste Prep Planner (starter)

A small Streamlit app that helps a restaurant kitchen decide how much of each dish to prep: it forecasts demand from past sales (same-weekday moving average), suggests prep quantities with a safety buffer and a visible reason, and requires a **human to approve** the plan. An LLM explanation is optional; without one it uses rule-based text.

A second tab, **Log plate waste**, lets staff pick the dish and upload a plate photo (or a bundled synthetic illustration). It estimates the leftover share (none / small ~25% / half ~50% / most ~75% / untouched), the staff member confirms or corrects it, and the app turns that into grams wasted per ingredient from `data/recipes.csv`. The estimate comes from an optional vision LLM or, offline, a rough pixel heuristic (demo only). Confirmed entries go into a session log (by dish and by ingredient, downloadable CSV) intended to feed the prep forecast.

- **Synthetic data only.** The included dataset is generated by a seeded script and is not from any real restaurant. Numbers in the app show how it works, not real results.
- **Prepared before the AI for Good Hackathon (19 Oct 2026, Oslo) as a disclosed starter template; built with AI assistance.** The hackathon prototype itself is built during the event (see `DISCLOSURE.md`).

## Run locally (Python 3.10+)
Windows PowerShell:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1     # if blocked: Set-ExecutionPolicy -Scope Process RemoteSigned
pip install -r starter/requirements.txt
pytest -q starter
streamlit run starter/app.py
```
macOS / Linux:
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r starter/requirements.txt
pytest -q starter
streamlit run starter/app.py
```
Optional LLM: set `LLM_API_KEY` (and `LLM_BASE_URL`, `LLM_MODEL`, `VISION_MODEL` [default gpt-4o-mini] for OpenAI-compatible providers) and `pip install openai`. Never commit keys.
Regenerate data: `python data/generate_synthetic_restaurant_data.py --seed 42 --out data/synthetic_restaurant_daily.csv` and `python data/make_sample_plates.py`

## Deploy on Streamlit Community Cloud
1. share.streamlit.io → **Create app** → from GitHub repo `antequeradiogo-stack/food-waste-prep-planner`.
2. Branch: `main` · Main file path: `starter/app.py`.
3. (Optional) Advanced settings → Secrets: `LLM_API_KEY = "..."` — not required; the app works offline without it.
4. Deploy. Dependencies come from `starter/requirements.txt` (root `requirements.txt` has the same pins).

## Limits
Same-weekday averages ignore weather, holidays and menu changes; sales history undercounts demand on sold-out days; suggestions are never orders. Plate-waste estimates are **unvalidated**: they need calibration against weighed plates in a pilot; camera at the plate-return station only, no guests in frame (GDPR). MIT licensed — see `LICENSE`.
